# 🛠️ API de Suporte Técnico

API desenvolvida para gerenciar chamados de suporte técnico, cobrindo todo o ciclo de atendimento: da abertura até a resolução.

## ✨ Funcionalidades

- **Abrir chamado:** registra um novo problema para atendimento.
- **Modificar chamado:** permite atualizar as informações de um chamado já aberto.
- **Solucionar chamado:** registra a solução aplicada e finaliza o chamado.
- **Remover chamado:** caso o problema não seja solucionado, o técnico responsável pode remover o chamado.
